# Originality and IP notes

Kept in the repository so that the boundaries are visible, not remembered. Based on the
reference guide supplied with the project (a summary of what is and is not protectable in a
life simulator).

**Mechanics that are free to use** (and used): a year-by-year text sandbox with an age button;
health, smarts, happiness and looks as the base stats; real-world analogues (schools, careers,
courts, property, inheritance); karma/stress/fame as hidden-or-secondary numbers; talents; the
minigame types for escapes, licence exams and infiltrations; the expansion themes (royalty,
music, sport, acting, crime families, business, space, spy work, zoo, vampires, cults).

**What we do not copy, and how that is enforced**
- *Trade dress.* Our layout is a three-column dashboard with an avatar, an event popup and a log with
  topic filters. The default accent colour is teal (it was green); the age button follows the accent.
- *Terminology.* The game does not use the competitor's brand names or its mode names. "God Mode"
  was renamed **Sandbox Mode**. Searches for the brand names in the code and the text return nothing.
- *Text.* Every event, choice and outcome is written for this game. Nothing is copied or paraphrased
  line by line. `CREDITS.md` lists the two open-licensed fonts; everything else is original.

**Where this game goes further** (the guide's "community requests"): interconnected economy (world
events move sectors; recessions cause layoffs; companies can be acquired), autonomous family (people
move abroad, rise, argue over wills), and a story log that can be read by topic.
