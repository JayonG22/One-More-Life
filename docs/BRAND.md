# One More Life — visual identity

The title is **One More Life**. The original mark combines a rounded person with
an open circle and a small leaf: a person, another beginning, and room for a life
to change. No lettering is squeezed into the app icon. The same mark appears in
the main menu, compact menu header, application/window icon and executable.

Source: assets/brand/mark.svg (transparent), app-icon.svg (dark rounded square),
app-icon.png (512 pixels), app-icon.ico (16 through 256 pixels). SVG is the editable
master. All paths were authored for this project. The previous supplied icons
remain historical and are not the current application identity.

Default colours follow the existing Fieldnotes theme: ink #151b1d, surface
#20282a, cream #f2eee4, sage #82b59b, amber #e7b36b. Nunito remains the typeface;
avatars keep their established drawn style. Avoid extra gradients, heavy borders,
bright panel fills, tiny text or a separate visual language for new features.
Other themes retain their identities with accent saturation capped at 0.58.
Panel shapes still vary by purpose; bulk/navigation/action roles remain distinct.

Story Life presents original campaigns first. Existing reference stories remain
separately labelled and supported for earlier saves; changing a display name is
not a rights clearance. No project-wide reuse licence has been added.
