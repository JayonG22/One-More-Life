# Player guide

## Starting a life

Import the repository's `project.godot` into Godot 4.4.1 and press F5.
Choose a mode on the title screen, then start a new life or continue a save.
The public v0.25 source contains Human Life, Pets Life and Prison Life.

Advance a year with **Age**. Read the log, resolve decisions, and spend your
time on activities, people, work and possessions. Each mode has different needs
and endings. A good outcome is not guaranteed by choosing a particular career
or building a high stat.

## Controls

| Key | Action |
| --- | --- |
| Space | Age up, or activate the selected button during keyboard navigation |
| 1–6 | Switch the six main tabs |
| Tab / arrows | Enter keyboard navigation and move focus |
| Enter / Space | Activate the focused control or acknowledge a result |
| Esc / Backspace | Go back in a menu |
| 1–9 during an event | Select an available choice |

A mouse click returns control to the mouse. Minigames show their own controls.
Adjust sound, motion, contrast and interface size in Settings.

## Saves

The game autosaves during play and provides save slots. Saves and settings live
in Godot's per-user application data location, outside the repository. Back up
that data before testing a new development build. Migration tests cover selected
older formats; they cannot guarantee every historical save will work.

## Reporting problems

Use the repository's [issues page](https://github.com/JayonG22/One-More-Life/issues).
Include the version, mode, operating system, what you selected, and what happened.
Remove personal information from screenshots and logs before sharing them.
