# v0.78.1 — Original Portraits

Restores the original avatar face artwork and font rendering used before the
drawn-portrait experiments. The actual earlier portrait glyph, 56% face sizing,
round backdrop, rim and optional charm are used, instead of an approximation.
Player, NPC, family, new-life and editor portraits share this renderer.

The editor shows the original working skin, figure, hair, outfit, background,
rim and charm controls. Original hair variants are free. Modern saved facial
features remain stored without rerolling or discarding them; controls that cannot
change the original portrait are hidden. Life-condition tooltips remain available.

In-face expressions and more facial customization matching the original design
remain unfinished. They are preserved as open accepted requirements. No separate
emotion emoji is added. All v0.78 gameplay, debt recovery and continuity fixes remain.
