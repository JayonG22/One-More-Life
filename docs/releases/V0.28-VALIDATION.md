from the rendered game, rather than mockups.

The broader suite includes legacy content/system checks, save migration,
simulation, menu crawling, layout, long-life performance, accessibility,
casino outcomes, minigame input, the 39-game bot sweep, and pet/prison interfaces.

## Limits

The downloadable Windows build is an unsigned portable preview with the official
Godot engine and a game pack. No Godot installation is needed. Other operating
systems and mobile exports have not been certified. Back up important saves.
Tests and screenshot review do not replace extended human playtesting or
establish comprehensive balance, accessibility or adaptation-rights clearance.

The environment emits a certificate-store warning and some existing resource
shutdown warnings. Final passing checks must contain no script errors.
Financial and health labels describe fictional game systems, not real advice.
