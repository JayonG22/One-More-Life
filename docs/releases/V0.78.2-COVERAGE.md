# v0.78.2 — original portrait additions

Matching original Windows face paths provide adult mood/health expressions,
12 free hair colours and 8 free iris colours. No new head/silhouette drawing is
introduced. Neutral and steady faces without colour changes remain the original
font glyph; unsupported ages, special hair and themed looks keep that glyph too.
New NPC colours are saved once; old saves default to Original, retaining their
previous appearance. Colour variants survive reload and actual-child transfer.

The original vectors and licence are recorded in CREDITS.md. The cache is bounded
to 128 shared textures and changes only when the look/condition changes.
Childhood, later-life and special-look extension coverage, further accessories,
visual acceptance and the wider 1.0 register remain OPEN. See NEXT-WORK.md.
