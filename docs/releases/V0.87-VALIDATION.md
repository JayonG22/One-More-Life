# v0.87 delivery notes

This is an unsigned local Windows development application, not v1.0. It has not
been published to GitHub or a paid store.

The package is exported with Godot 4.4.1 for Windows x86_64. Compilation is
required to produce the application; it does not establish runtime correctness.
The application, PCK, documentation, credits and dependency notices are bundled.
`BUILD.txt` identifies the source revision in both the application and source ZIPs.

The owner requested no testing and will playtest. No game launch, automated
tests, simulations, UI walkthroughs or archive tests were performed for this
update. Development consisted of source review, implementation and export.
Behavior through ageing, save/load and generation transfers remains subject to
owner play acceptance.

Extract the full Windows ZIP and open **One More Life.exe**. Keep
**One More Life.pck** beside it. Existing save paths are retained. SHA-256
values accompany the archives. The completion register retains the open scope.
