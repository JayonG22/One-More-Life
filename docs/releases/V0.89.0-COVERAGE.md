# Historical v0.89 development slice — Relationship continuity

> Archived work note, not a separate update release. This implementation slice
> is consolidated into [v0.89 — One More Life, Unified](V0.89-COVERAGE.md).

This interim integration pass connects event friction, relationship bonds, NPC
memories and Life Threads through the shared event resolver.

- Positive changes to trust, affection, respect and romance now follow the same
  friction result as the visible relationship outcome. A backfire cannot quietly
  grant the full positive bond change; a snag reduces its size.
- Significant combined bond and closeness changes save one accurate NPC memory
  for the selected person. A larger change also updates that person's continuing
  Life Thread; authored memorable scenes keep their explicit memory behavior.
- The remembered outcome uses the resolved event text, including the friction
  note, so the saved account matches what happened.
- Small routine shifts stay out of persistent memory. Repeated moments merge in
  the existing thread history rather than creating a new activity list.

This is partial v0.89 unification. The all-mode navigation, display, accessibility,
audio, balance, migration, larger save, content and release-acceptance audits
remain open in [the four-update campaign](../FOUR-UPDATE-CAMPAIGN.md) and
[completion register](../COMPLETION-REGISTER.md). The owner will playtest this
interim build; no gameplay testing is claimed here.
