## Known limits

- No full new avatar artwork, recorded soundtrack, mobile package, signed release
  or complete TV catalog is claimed.
- A child's previously simulated NPC state is preserved where it exists. Older
  NPCs lack detailed qualifications, job salaries or complete personal histories;
  missing details use the game's existing school and job scaffolds.
- This is a portable Windows preview. Other platform exports need their own
  build and launch checks. Review [release readiness](../RELEASE-READINESS.md)
  before a public/commercial release.
