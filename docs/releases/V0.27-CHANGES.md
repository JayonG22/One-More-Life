# v0.27.0 — Family viewpoints and calmer menus

Organized the title menu into resume, new-life and categorized secondary actions.
Added genre/search navigation to TVLife, distinct story panels, witty aliases,
dark palettes and a softer, varied borderless shape system.

Minigames now pause for instructions and resume the active board. Fixed duplicate
settlement/completion, reduced-motion casino effects, the last three Cell Search
keyboard shortcuts, High–Low odds messaging and bright blackjack cards.

Added living-child viewpoint transfer while leaving the parent alive and retaining
the child's recorded life. Updated post-death succession to retain personal state
and money. Added a confirmed, non-graphic suicide ending for adult family lives.

Added 20 adult narrative scenes with 60 choices and 120 outcomes, including
delayed consequences for intimacy, betrayal, serious crime, pressure and debt.
Settings can suppress new additional mature arcs while preserving consequences
already underway. These are fictional non-graphic narratives.

Consolidated project documentation into player, developer, art, history and release
categories. Public GitHub documentation cleanup is merged separately; this gameplay
preview has not been published there. See [coverage](V0.27-COVERAGE.md) and
[validation](V0.27-VALIDATION.md) for scope and verification.
