# v0.31.1 validation

Ten targeted regression gates passed in isolated save folders with muted audio.
The original v0.31 full release-gate results are preserved separately; the entire
44-gate suite was not repeated for this addition. These checks cover the changed
shopping, ownership, save, menu and layout behaviour; they do not prove every
possible combination or complete the v1.0 roadmap.

Shopping checks cover every purchasable retailer product, all seven home models,
all eleven cars and all 37 animal varieties, including price, functional tags,
save/reload and resale. They reject invalid, underage, unlicensed and unavailable
purchases. Animal fees are recomputed instead of trusting supplied prices; living
capacity and migration are checked. Denied mortgages preserve the balance.

Rendered UI checks cover browsing without payment, differing electronics stock,
button roles, ten selectable themes, normal and 175% interface sizes, actual text
wrapping and label/button geometry. Shared layout checks cover common panels at
1600×900, 1920×1080, 1366×768 and 1280×720. Final screenshots were inspected.
The existing study-bundle check still plays the real quiz through its buttons,
checks actual grades/costs and verifies the annual repeat lock. Assertions about
old button wording were updated to the shorter copy and checked against price
and saved annual state; the behaviour assertions were retained.

The Windows pack is checked with its bundled engine in muted headless and rendered
startup runs. The 563 catalogue assertions are also run against exported resources,
including the new JSON catalogues, using an external test harness. ZIP integrity,
SHA-256 hashes and source-file equality are checked during packaging.

Known environment noise: this Windows runtime reports a root-certificate-store
warning; it does not prevent these offline checks. No passing check reported a
script error. These are local portable previews; nothing was uploaded to GitHub.
