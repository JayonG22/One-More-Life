## Implemented in this checkpoint so far

- Repaired the high-school graduation event. Successful graduation now queues it
  once at the real diploma transition, before random encounters.
- Bound the ceremony to the student's classroom teacher and a current classmate.
  Choices affect those relationships and save the memory; every outcome
  schedules a callback with the same people.
- The callback can still appear as a memory if either person has died. Its family
  key also participates in the shared event cooldown across lives.
- Relevant completed school projects now improve matching university admission
  estimates alongside GPA and extracurriculars. The major picker previews the
  same estimate used when applying and clarifies tuition and aid factors.
- Job listings show a short fit estimate and open a detail panel with salary,
  competition, the role's specific duties, and the school/work factors that help
  or hurt before an application uses time.
- A static catalog review found 95 ordinary job definitions and at least two
  job-specific duty entries for each. This is a content inventory, not proof of
  in-game behavior or balance.
