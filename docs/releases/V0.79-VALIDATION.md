# v0.79 focused validation

The exported Windows GUI game launches directly. Its packaged resources pass
321 application checks and 94 connected-follow-through checks, with zero
failures. The latter include actual source hooks, shuffled saved choices,
limited fees and rewards, trust and expiry, missing contacts, exhausted pools,
save/reload and parent/child ownership. New support is held in the owner’s case;
it does not create a shared NPC favour reward.

Focused source checks also passed: 91 journey checks, 38 employment checks,
274 portrait/editor checks and 69 journey interface checks. The exported game
passes the same 274 portrait/editor and 69 interface checks. The interface
checks include normal and enlarged text, navigation versus activity buttons,
and opening a real named follow-up decision. Screenshots were inspected.

The portrait checks cover original adult faces and skin tones, free colours,
five accessories and three facial details, stable legacy defaults, saved NPC
variants, reload and child transfer. Unsupported ages and looks retain their
original glyphs. These checks do not establish all-age cosmetic coverage or
human visual acceptance.

Audio is muted with the Dummy driver. Isolated test folders protect existing
saves. No completed whole-life simulation batch was used for this release.
These are targeted checks, not proof of whole-game balance, every event chain,
every career branch or v1.0 acceptance. All broad completion gates remain OPEN.
The local sandbox certificate-store diagnostic is not a network-service test.

The final Windows and tracked-source ZIP archives are checked for integrity;
SHA256SUMS-v0.79.0.txt records their fingerprints.
