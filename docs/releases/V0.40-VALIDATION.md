# v0.40 focused validation

Testing follows the user's request to conserve time: targeted checks and short
smoke tests, with isolated saves and muted audio. No large whole-life simulation
batch, historical full-suite gate or routine 20+ bot lives was run.

- **Connected-life behaviour:** 91 checks, zero failures. Exercises actual event
  resolution, save/resume and stale choices; promise deadlines and costs; co-parent
  contact; multi-year school/council delivery and adult pathways; practice versus
  scored limits; contracts and late invoices; move/migration/home boundaries;
  institutions; criminal hearing stages; actual heirloom/company ownership,
  dormant company income paid once, living transfer and inheritance cash/progress;
  optional themes and expressions; all eleven new mode sequences; and one complete
  branching route through each of the four original campaigns.
- **Rendered UI and challenges:** 62 checks, zero failures. Eight categories and
  the hub at scales 1.0 and 1.75; wrapped button bounds; navigation click-through;
  actual human More-menu access; the real minigame intro/play/result flow; all nine
  workshop types through five rounds with keyboard input and single-result guards.
  Screenshots of the enlarged hub and hosted budget challenge were inspected.
- **Existing work/training regression:** 37 checks, zero failures. Preserves the
  v0.32 career, qualification, contract, promotion and income-accounting behaviour.
- **Export/package verification:** the Windows resource pack is started using its
  bundled runtime and the focused connected-life and career checks are run against
  exported resources. ZIP integrity, exact tracked source bytes and SHA-256
  checksums are verified before delivery. Runtime logs are retained outside source.

These checks verify the exercised paths, not every possible life, balance or
long-term save migration. The full coverage and reliability phases remain on the
roadmap. The four campaigns each have three authored endings; this focused run
plays one route per campaign rather than repeatedly simulating every life.
