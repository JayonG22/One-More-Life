# v0.85 delivery notes

This is an unsigned, local Windows interim build. It is not v1.0 and has not
been published to GitHub or a paid store.

The Windows x86_64 application was exported with Godot 4.4.1. The executable has
the Windows GUI subsystem, and both Windows and source ZIPs passed archive
integrity and required-file checks. SHA-256 values are in the adjacent
`SHA256SUMS-v0.85.0.txt` file.

The owner asked to do their own playtesting. No automated tests, simulations,
UI walkthroughs or game launch were performed. The export compiled the project
for packaging; it did not check runtime behavior. Remaining features and release
gates stay open in the [completion register](../COMPLETION-REGISTER.md) and
[next-work list](../NEXT-WORK.md).
