# v0.81 — More life, less clutter

One integrated quality update addresses the candid review and the request for
consistent, compact events, minigames and panels. It extends the existing game;
the original avatar artwork and accepted completion checklist stay intact.

| Area | Delivered in this build |
| --- | --- |
| Navigation | Seven Life activities groups retain every existing destination. Health headings distinguish appointments/family care, mood/grief/stress and dependence/aftercare. Existing direct shortcuts remain. |
| Card design | Events, large menus and minigames share dark, borderless asymmetric rounded frames and compact icon badges. Events lose their redundant nested card and large stacked header. Long event/menu contents scroll inside a bounded frame; the event heading stays visible and keyboard focus follows scrolling choices. Trophy, shop and mission layouts wrap to the available space. |
| Minigame presentation | Smaller introductions/results, calmer background dimming, activity badges and breathing room around active boards. Enlarged settings preserve more board room; original controls and help remain. |
| Hands-on play | Repair uses inspection/toggles, music uses note sequences, negotiation uses offer/scope sliders with several scoring factors. All are untimed, checkpointed and guarded against duplicate outcomes. Earlier saved workshop attempts keep their old format. |
| NPC initiative | NPCs make guarded annual goal progress, independently learn or protect their energy, build bounded social circles using living people, complete goals and change priorities. The player receives no NPC cash/skill reward. Activity histories use actual identities. |
| Shared moments | Eighteen optional, age-filtered authored scenes with three reasonable approaches, preference-sensitive trust, learning/mood/stress trade-offs and next-year conclusions. One attempt per person/year; exhausted optional pools do not replay or charge. |
| Parenting | Forty-two scenes, fourteen in each age band. Reworked punishment options become reasonable alternatives. A child's saved preference affects trust; choices influence learning/mood and parental stress. Saved next-year outcomes follow that actual child through viewpoint transfer. |
| Rivalries and wording | New friction scenes offer reasonable third routes, with respect/stress trade-offs. Earlier pending rivalry choices keep their saved wording. Shorter messages remove implementation jargon from selected player-facing results. |

NPC autonomy remains a modest priority/social layer: it does not simulate every
NPC occupation, romance or household expense. These authored pools are finite;
they increase variety without promising unlimited scenes. Six of the nine newer
workshop activities retain their existing quiz format. The wider minigame audit
and all remaining accepted scope stay in the completion register.

This is a native Windows development application, not a v1.0 completion claim
or a public GitHub release.
