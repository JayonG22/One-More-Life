## Corrections found during verification

- The centuries-long performance fixture began with a vampire destiny, which
  still permits the player to decline becoming a vampire. It now starts as an
  actual vampire and avoids choices that cure it. Normal play retains those
  choices. This makes the intended performance measurement reproducible.
- The legacy career-content test now excludes the imported NPC occupation
  placeholder from the advertised-career event quota. The placeholder is not
  offered on job boards; ordinary workplace scenes still apply.
- The release gate now checks process exit status and script errors as well as
  expected result text. Production export tooling stops on failed/missing
  exports and refuses to overwrite an existing output folder. The Bash
  multi-platform export script was reviewed, but could not be executed here;
  the Windows preview uses a separately verified pack-export path.

## Package and testing limits

The Windows ZIP bundles the official Godot engine plus a game pack and launcher.
It is a portable preview, not a signed production executable. No mobile, Linux
or macOS export is certified by these checks. Audio logic remains enabled in the
game; muting was applied to automated runs, not the delivered player's settings.

The sandbox reports a root-certificate-store warning. Existing anchor/resource
shutdown warnings also occur in some tests. Final passing gates must have no
script errors. Automated tests and screenshot review are not an exhaustive
manual playthrough, balancing study, accessibility audit or rights clearance.

TVLife still uses recognizable settings and selected plots despite the aliases.
See [release readiness](../RELEASE-READINESS.md) before a wider release. Older NPC
records do not contain a full playable life; transfer preserves recorded details
and uses existing scaffolds for missing information.

The source and Windows preview archives passed ZIP integrity checks. Package
file hashes are listed in `SHA256SUMS-v0.27.0.txt` alongside the archives.
