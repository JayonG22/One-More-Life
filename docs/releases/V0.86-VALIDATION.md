# v0.86 delivery notes

This is an unsigned local Windows development package, not v1.0. It has not
been published to GitHub or a paid store.

The project is exported using Godot 4.4.1 for Windows x86_64. Export compilation
is part of creating the application; it does not establish runtime correctness.
Both application files, documentation, credits and dependency notices are
included. The source ZIP records the same source revision in `BUILD.txt`.

The owner requested no testing and will playtest the game. No automated tests,
simulations, game launch, UI walkthrough or archive tests were performed for
this batch. Source review and packaging were performed. Remaining acceptance
stays open, including behavior across ageing, saves and generation transfers.

Extract the entire Windows ZIP and open **One More Life.exe**, keeping
**One More Life.pck** beside it. Existing save paths are retained. SHA-256
values accompany the archives.
