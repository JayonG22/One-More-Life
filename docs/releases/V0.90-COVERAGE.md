# v0.90 — Candidate Readiness & Lasting Context

**Status: in progress.** This is the first source-development checkpoint in the
staged local-review sequence toward v1.0. Open v0.89 and earlier scope carries
forward. A local Windows review package was exported on 5 October 2026. It is
not a tested candidate or a completed milestone.

This pass adds six short, optional story threads to the authored event library:

- At age five, a new classroom can feel enormous. The player chooses how to
  settle in; a callback returns to the first-classroom memory a few years later.
- A school group project lets the player organize the work, take on too much, or
  ask a teacher to reset the plan. Choices affect school performance, stress,
  smarts and the named classmate/teacher relationships. A later folder callback
  reflects on the collaboration.
- A new worker can document an unwritten routine, ask as they go, or figure it
  out alone. The result changes work performance, stress and coworker closeness.
  A later callback lets the player help a new starter.
- At age thirty, a crowded weekend asks the player to choose between a promise,
  one gathering, or doing too much. Employed players can also face a separate
  handover choice about preserving a departing teammate's knowledge; both can
  return as later callbacks.
- A community noticeboard can become a safe shared workday, a small supply
  contribution, or a task left for someone else. The paid option is shown and
  disabled when cash is short. A later noticeboard callback records whether the
  place still feels shared.

All six starting stories are one-time scenes with named NPCs. Their callbacks
are scheduled from the chosen outcome, so the scenes connect a decision to a
person, a practical record and a later moment. Existing saved stories are not
rewritten. Each starting scene also shares a story-family key across save slots,
so the existing familiarity selector can cool down the same kind of scene in a
different life. A finite story library still cannot promise endless novelty.
