# Art documentation

The game currently relies on emoji, fonts and elements drawn in code. The files
below describe potential custom artwork; they do not claim that artwork exists.

- [Art brief](ART-BRIEF.md): format, portrait parts, interfaces and scene assets.
- [Asset list](ASSET-LIST.md): priorities and where icons are used.
- [Emoji inventory](ASSET-EMOJI-INVENTORY.csv): historical machine-readable inventory.

Start with a coherent avatar kit, mode emblems and a small set of frequently
seen icons. Test them at actual display sizes before expanding the inventory.
Record creator, source, licence, permitted uses and attribution for each new asset.
Do not use artwork taken from television shows, other games or image searches
without suitable permission.
