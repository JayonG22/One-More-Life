# One More Life roadmap

## Current work

The active milestone is **v0.92 — People & Relationships**. Unsigned interim
local review packages are available through v0.91; their wider scope and owner
acceptance remain open. v0.92 is still in progress and is not packaged. No
candidate release or v1.0 acceptance is claimed.

The current task order starts with the
[prior-update closeout board](docs/FEATURE-CLOSEOUT-BOARD.md): finish or clearly
account for partially delivered features before adding fresh feature scope.
The board captures work status without reducing the accepted v1.0 requirements.

The owner has approved distributing the remaining work across substantial
v0.90–v0.99 checkpoints. Each checkpoint is a local development package for
owner review once its stated scope is ready; these are not public stable releases.
The final consolidated release remains **v1.0** after acceptance.

See [v0.92 coverage](docs/releases/V0.92-COVERAGE.md) for current progress and
[work remaining](docs/NEXT-WORK.md) for the detailed task list.

Cross-cutting requirements—dark readable presentation, concise descriptions,
stat-based outcomes, saved consequences, varied events, safe save migration and
honest rights/credits—apply in every checkpoint. The [four-update campaign](docs/FOUR-UPDATE-CAMPAIGN.md)
and [completion register](docs/COMPLETION-REGISTER.md) remain the detailed
acceptance records. The [BitLife comparison](docs/BITLIFE-COMPARISON.md) is a
reference audit, not a claim of parity or a substitute for One More Life's own
identity.

## Release gates

The feature-complete gate remains open. v1.0 requires the accepted base-game
scope to be implemented and connected, save and transfer behavior to be reliable,
the application and documentation to agree, and the owner to complete the
requested gameplay acceptance. A successful build alone does not close these
gates. Known requirements cannot be deferred as post-v1.0 maintenance.
