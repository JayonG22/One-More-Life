One More Life combines project-authored game code and content with third-party
engine and font resources. This table records the identifiable dependencies;
it is not a blanket ownership or legal-clearance guarantee.

| Resource | Source and notice |
| --- | --- |
| Engine | [Godot 4.4.1](https://godotengine.org/license/), MIT; include the engine notices when distributing its binaries |
| Nunito font | SIL Open Font License 1.1; [bundled notice](fonts/LICENSE-Nunito-OFL.txt) |
| Noto Color Emoji font | Google; SIL Open Font License 1.1 for the bundled font; [bundled notice](fonts/LICENSE-NotoColorEmoji.txt) |
| Original lifespan portrait extensions | Microsoft Fluent UI Emoji flat vectors, MIT; [source and attribution](assets/portraits/original/SOURCE.md), [bundled licence](assets/portraits/original/LICENSE.txt). Existing paths supply the matching Windows silhouette, hair, eyes, nose and mouth; project code changes colours and facial expression |
| Procedural music and effects | Generated by project code in `autoload/fx.gd` |
| Interface icons and visual effects | Emoji plus project code and shaders |
| Current app logo/icon | Original project-authored vector mark in `assets/brand/mark.svg` and `app-icon.svg`; rendered by Godot, with Windows icon sizes converted by Pillow. No external art, traced logo, image-generation model or paid asset was used |
| Historical app icon | Earlier owner-supplied `icon.png`/`icon.ico` retained as historical assets; their earlier provenance entry remains unresolved. They are not the active application icon |
| Simulation writing | Authored for this project; later contributions require their own provenance review |

The repository does not currently contain a project-wide licence granting reuse
of its original code and content. Dependency licences do not license the entire
game. See [release readiness](docs/RELEASE-READINESS.md).

The current Story Life catalog contains twelve project-authored campaigns.
The four earlier TV-based preview stories have been replaced with six additional
original campaigns, as chosen by the owner. Loading an earlier preview save
archives that reader's saved choices and log before starting its original
replacement; completed saves remain completed. Old releases and Git history
are historical material, not the current public story catalog.
