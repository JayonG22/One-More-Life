# Voice sounds

The game makes its own human-like voices (cheers, gasps, sighs, laughs) in code, so it works with no files here.

To use real recordings instead, drop files in this folder named after the sound, as .ogg, .wav or .mp3:

yay, woo, ooh, oh, ugh, gasp, sigh, laugh, hmm, aww, ouch, cheer

Only use clips you have the right to ship. Pixabay's content licence allows free use without credit, but check the page for each clip, and list what you added in CREDITS. Do not use recordings taken from other games.
