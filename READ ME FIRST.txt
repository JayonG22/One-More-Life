ONE MORE LIFE — public source

This repository contains a Godot project. It does not include prebuilt game
downloads. No GitHub releases are currently published.

Install Godot 4.4.1, import project.godot and press F5.
See README.md and docs/PLAYER-GUIDE.md for the current instructions.

For a separately downloaded binary package, use that package's own release
instructions. Filenames, platforms and signing status depend on that release.
