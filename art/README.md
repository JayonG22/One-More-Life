# ONE MORE LIFE — Art Production Pack

This package turns the uploaded art brief and emoji inventory into a production manifest.

Manifest rows: 2,854

Important:
- Rows marked `explicit` are directly named in the uploaded brief.
- Rows marked `inventory` correspond to every distinct stock emoji in ASSET-EMOJI-INVENTORY.csv.
- Rows marked `slot` exist because the brief gives a count but not the exact semantic ids/names. Those need the source game data (achievements.json, jobs.json, majors.json, missions.json, event JSON, etc.) to replace numbered slots with exact filenames.
- The style guide deliberately removes glossy / generative-looking cues and targets 24 px readability.

This is the production map for the complete art set; it does not pretend that unnamed source-data assets have names that were not supplied.
